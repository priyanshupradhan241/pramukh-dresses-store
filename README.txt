PRAMUKH DRESSES WEBSITE

FILES
- index.html: complete responsive storefront
- images/: the six product photos supplied for this project

BEFORE PUBLISHING
1. Open index.html and find: const STORE_WHATSAPP = "91XXXXXXXXXX";
2. Replace 91XXXXXXXXXX with the shop WhatsApp number (country code 91 + 10-digit number; digits only).
3. Confirm product names/descriptions with the shop owner.
4. Add actual prices, sizes, colours and stock only after the owner confirms them.
5. Add the real business address/contact details and approved delivery/return policy.

ORDERING
- Cart and WhatsApp order request are implemented.
- The site intentionally shows "Price on enquiry" because product prices were not provided.
- Real online payments are NOT enabled. Add a payment gateway only after the shop owner opens/configures the merchant account and a secure backend/serverless integration is set up. Never collect or store card details in this static website.

GITHUB PAGES
Upload index.html and the entire images folder to the root of the new repository.
Then in GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
